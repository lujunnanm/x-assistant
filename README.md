# X 文案助手 v2.0.21

运行在 X 网页中的本地 Chrome/Chromium 扩展，提供互动、定时发帖、文案库管理和低曝光帖子清理功能。

## 功能

- **互动循环**：读取候选帖子，由本地 DeepSeek 桥接服务生成回复，再由扩展执行回复、点赞；可选择是否关注。
- **定时发帖**：由 DeepSeek 根据文案库素材生成新帖，每轮随机等待 **30–50 分钟**。
- **低曝光清理**：每隔 10–30 秒检查并删除一条发布超过 24 小时、曝光低于 50 的本人原创帖子；排除回复、转帖、文章、置顶和推广内容。
- **文案管理**：新增、编辑、启停、删除以及 JSON 导入导出。
- **循环保护**：模块独立启停、跨标签页执行锁、账号校验、发送回执、草稿保护和异常停止。

扩展不会在安装或更新后自动执行公开操作，所有模块均需手动点击“开始”。

## 安装

1. 下载或克隆仓库。
2. 打开 `chrome://extensions/`，开启“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本仓库目录。
4. 刷新 `https://x.com/`。

不要同时启用旧版和新版。

## DeepSeek 本地桥接

API Key 仅保存在本地 Python 进程内存中，不写入扩展、仓库或日志。

```bash
python3 bridge/deepseek_bridge.py
```

随后打开 `http://127.0.0.1:18765/` 保存 API Key。浏览器或桥接服务重启后需要重新输入。

`bridge/deepseek_bridge.py` 中的 `EXT` 必须与浏览器扩展详情页显示的扩展 ID 一致。若本地加载后 ID 不同，请先修改该值再启动桥接服务。

## 使用提醒

- X 页面结构、账号限制和平台回执可能变化，公开操作前请先小规模测试。
- “发送结果未知”不会自动重试，需先在 X 记录中人工核对，避免重复发布。
- 停止按钮不能撤回已经发送给 X 的请求。
- 请遵守 X 的平台规则及适用法律。
