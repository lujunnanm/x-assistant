# 神圣计划 v5.0.1

在已登录的 X 页面中，由一个协同开关调度发帖、互动和通知回帖。保留当前石墨黑 / 橙色按键界面及 50% 显示尺寸。

## 使用

1. 更新原有扩展目录后，在浏览器扩展管理页重载 **原有神圣计划扩展**，再刷新 X 标签页。
2. 工具栏扩展图标打开配置页。检查原密钥、文案、配图引用，再进入“时间控制”。
3. 设定秒数，点击“保存时间设置”。最短和最长相同即固定时间。
4. 在 X 上确认当前账号，再手动点击“启动协同”。更新和重启保持停止；不会因为升级自动发布。

**不要删除原有扩展后重新安装，也不要更换已加载目录**：扩展 ID 变化会让原浏览器存储不可见。交付压缩包是备用源码包，不包含用户浏览器里的密钥或运行数据。

## 时间控制

| 项目 | 默认值 | 应用边界 |
|---|---:|---|
| 发帖冷却 | 1200–1800 秒 | 已确认发帖后及主动跳过后的下轮 |
| 互动冷却 | 20–30 秒 | 处理完一条互动后，按账号在后台记录截止时间 |
| 逐条回帖冷却 | 10–20 秒 | 确认发送一条通知回复后 |
| 通知检查间隔 | 600 秒 | 每轮通知处理结束后开始下轮等待 |
| 单次通知处理时长 | 300 秒 | 每轮通知工作窗口的上限 |
| 首次启动等待 | 30 秒 | 尚无历史发帖排程的账号 |
| 异常重试等待 | 30 秒 | 可恢复错误后的协同重试 |
| 发帖提前交接 | 30 秒 | 发帖前让出页面，仍要等待在途事务收尾 |

保存后用于下一次计时，**不改写已经开始的冷却截止时间**。发帖和互动冷却按账号持久化，停止、刷新或浏览器重启不清除这些截止时间。通知排程随协同状态保存；只有同一账号才能复用。新通知工作窗口仍受发帖优先和页面锁限制，时间不是平台成功回执。

## 保留的功能与保护

- 发帖参考文案及配图、DeepSeek 生成、平台发送回执校验、按账号保留发帖排程。
- 交友帖筛选（曝光不少于 500）、自动关注开关、交友话题搜索开关；当前互动不执行点赞。
- 通知只处理最近 24 小时、明确回复当前账号的评论，最新优先；独立于自动关注开关。
- 互动入选帖子不再因内容价值低而跳过；低信息帖子改用交友或请求回关文案。技术失败不标记成功，未知发送保留证据且不自动重发。
- 文案编辑 / 启停 / 删除 / 导入导出、替换前备份；已关注库只读采集及导出、运行日志。
- 跨标签页互斥、账号变更检查、可取消等待、用户草稿保护、扩展失效后停止。

## 精简范围

删除已无入口的旧帖清理代码、无效独立模块按钮、关注冷却触发回帖的废弃支路、无调用的回帖尾句函数、十份过期迁移代码 / 数据；合并三处相同互动等待。现有文案库不再被升级迁移覆盖。50 张旧配图全部保留，因为已存文案仍可能引用它们。

悬浮窗样式从多轮覆盖改为一份生效样式；原石墨纹理从内嵌 Base64 移为独立本地 PNG。过期静态预览同步为三模块界面。

## 文件职责

- `time-policy.js`：唯一时间字段、默认值、范围验证及随机采样，供后台、配置页、页面脚本共用。
- `time-client.js`：一次读取、一个配置变更订阅，提供实时设置及后台冷却接口。
- `background.js`：串行状态变更、来源验证、时间配置存储、互动截止时间及发帖回执落库。
- `scheduler-core.js` / `scheduler.js`：可测试的调度规则及运行控制；发帖优先，通知到期交接。
- `view.js` / `overlay.js`：悬浮窗与互动驱动分离；`posting.js` / `notifications.js`：各自平台事务。
- `panel.html` / `panel.js` / `panel.css`：配置与资源管理。

无第三方运行依赖。浏览器需要支持 Manifest V3、扩展存储和 Web Locks；测试使用 Node.js 内置测试框架。

```sh
npm test
```

## v5.0.1 · 互动回复与精简界面

- 只将已确认成功、发送未知和在途记录用于长期去重。旧的 AI 跳过、未提交失败、弹窗取消记录重新具备候选资格，不清除任何未知发送证据。
- 互动 AI 返回 `skip` 时改为同语言的简短交友回复；中文默认兜底为“来交个朋友，方便的话回关一下。”
- 互动允许交友和请求回关表达；不在关注成功前虚构“已关注”状态。通知回帖继续执行高价值筛选，不添加交友回关尾句。
- 作者去重在平台确认成功后生效。生成失败、未提交失败和结果未知仍分类记录，不会被误认为成功。
- 删除悬浮窗“时间设置”入口和所有模块状态小字；冷却时间仍由后台时间模块管理。
- 保留发送错误的原始原因，不再仅因回复框仍打开就统一标成弹窗跳过。
- 配置页“运行日志”新增本次互动进程的筛选排除和尝试结果计数。筛选原因按帖子＋原因去重；尝试结果按实际尝试计数。交接后重启驱动会重置本次进程计数。

本次没有降低曝光门槛、恢复 3:1 轮换、清除成功记录、自动重发未知结果或自动启动任务。Chrome 和 Ego Lite 重载验证后均保持停止。
