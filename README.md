# 灯神 2 · v2.0.3

面向 X 和知乎的 Chromium 浏览器扩展，使用 Manifest V3。本仓库仅保留当前最新版插件源码、测试及必要资源，不存放旧版安装包和用户运行数据。

## 功能

- **发帖**：独立文案库、图文素材及发送结果核对。
- **互动**：从首页或搜索时间线选帖，生成回复；自动关注仅接受原生蓝 V，并在点击前再次核验。
- **回帖**：每轮先扫描提及，再逐条检查最近 7 天的本人原帖；长帖持续向下读取，处理直接评论和楼中楼。
- **回关**：独立检查认证关注者；仅处理原生蓝 V，其他认证或无法确认的目标跳过。
- **“+”入库**：支持 X 帖子及知乎回答、专栏文章的文字和配图。
- **删帖管理**：提供独立的删帖管理页面。

各模块独立选择，由总开关统一控制。启用 `xAssistantManagedServiceV1.restartOnFailure` 时，失败工作页使用持久化的三分钟倒计时重建；手动关闭会取消倒计时，未知发送状态和平台冷却不会因此解除。详见 [工作页重启策略](RESTART-WATCHDOG.md)。

## 安装与更新

1. 下载仓库源码并解压到固定目录。
2. 在 Chrome / Ego 的扩展管理页开启开发者模式，选择“加载已解压的扩展程序”，选中包含 `manifest.json` 的目录。
3. 在插件设置页配置 DeepSeek API Key、文案库及需要的模块，再按需开启总开关。

已有安装请先关闭总开关，在原安装目录替换文件后重载扩展；不需要卸载。浏览器中的密钥、文案和运行记录不在本仓库内，不会随源码下载或迁移。不同浏览器的本地存储相互独立。

## 开发与验证

依赖 Node.js 及其内置测试运行器；无第三方 npm 依赖。

```sh
npm test
```

- `manifest.json`：插件版本、入口与权限。
- `background.js`、`bg/`、`managed-service.mjs`：后台和工作页管理。
- `panel.*`、`deletion.*`：设置及删帖界面。
- `bridge/`：AI 任务规则。
- `tests/`：离线回归测试。
- `icons/`、`post-images/`：当前版本依赖的打包资源；固定的 50 张 JPG 为既有配图资源，测试会校验它们。

本次同步验证记录见 [VERIFICATION.md](VERIFICATION.md)。离线测试通过不代表已经重新验证真实网站、真实 AI 请求或实际发送。
