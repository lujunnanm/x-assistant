# 神圣计划 v3.0.15

面向 X 的本地 Chromium 浏览器扩展，用一个悬浮窗总开关协调自动发帖、主动互动和通知回帖。三个模块按优先级轮流工作，不同时抢占页面。

## 功能

### 自动发帖
- DeepSeek 根据文案库选题生成短帖，保留参考文案的相关话题标签及原有 @grok。
- 成功发送后随机等待 **30–50 分钟**。
- 按账号保存上次、下次发帖时间；重启保留未来排程，已过期的排程重新启动后立即处理，不补发积压任务。无已有排程时约 30 秒启动缓冲。

### 主动互动
- 自动寻找帖子，由 DeepSeek 生成回复，再点赞；自动关注可选。
- **关闭自动关注**：只选择可见曝光 **高于 5000** 的帖子，不要求作者关注当前账号；回复后随机 **3–5 秒**点赞，每帖结束、跳过或可恢复失败后随机 **5–10 秒**再找下一帖。
- 开启自动关注：按未关注、未关注、未关注、已关注作者循环；回复到点赞等待 5–10 秒，点赞到关注等待 5–10 秒，帖间等待 40–60 秒。
- 连续六次滚屏未找到目标，刷新主页继续寻找。

### 通知回帖
- 检查通知中的回复，只处理**滚动最近 24 小时内**、明确回复当前账号且没有本地已处理记录的评论，发送前再次校验时效。
- 跳过自己和 Grok；按账号、评论 ID 去重，保留未知发送状态，防止自动重复发送。
- 每条间隔 **10–30 秒**，不附加交友或回关尾句。
- 没有可回复项、扫描达到上限或加载停滞时，本轮休息，不把整个协同停止；扫描上限不代表所有评论均已处理。

### 多语言 AI
- 原帖或评论主要是什么语言，就用什么语言回复，尽量保持简繁体习惯；混合语言按主要内容判断。
- 主动互动的交友、回关尾句同样使用该语言；通知回帖无尾句。
- AI 可主动跳过不适合回复的内容；校验失败重新生成一次，不重试已提交的公开回复。
- API 错误显示在悬浮窗；认证、余额或权限错误停止协同，避免空转。

### 协同与安全控制
- **发帖优先 → 互动 → 回帖**。互动在发帖冷却期工作，累计实际工作 60 分钟后休息 30 分钟，由回帖利用休息窗口。
- 回帖在下一次发帖或互动启动前 30 秒停止接新任务；已提交的动作等待结果，不盲目重发。
- 可从 X 不同页面启动，自动导航到工作页面。账号校验、跨标签页锁及页面操作锁减少冲突。
- 遇到可取消弹窗、未发送回复残留、保存草稿弹窗：取消或放弃草稿，跳过任务。无法安全处理或发送结果未知时停止等待人工核对。
- 低曝光清理保留独立开关，与协同互斥：每隔 10–30 秒处理一条超过 24 小时且曝光低于 50 的本人原创帖子，排除回复、转帖、文章、置顶及推广。
- 文案库支持添加、编辑、导入与导出，并提供运行日志、模块状态灯及倒计时。

## 安装与 API 配置

1. 下载或克隆仓库，在 Chromium 浏览器的扩展管理页开启开发者模式，选择“加载已解压的扩展程序”，加载仓库根目录。
2. 停用旧版本，刷新已登录的 X 页面。
3. 打开插件管理页，在 **DeepSeek API** 区域保存有效密钥。保存时先进行认证检查，启动协同前再次检查。
4. 在 X 悬浮窗启动协同。安装、更新或浏览器重启后默认停止；已运行协同的普通页面刷新可恢复安全等待状态。

插件直接调用 `https://api.deepseek.com`，使用 `deepseek-flash`，不再需要启动本地 Python 桥接服务。仓库的 `bridge/*-rules.txt` 是生成规则，Python 桥接文件仅保留供旧版兼容参考。

**密钥存放在当前浏览器的 `chrome.storage.local` 中，重启保留，不写入源码、不随文案导出。该存储不是操作系统钥匙串，不提供同等级加密保护。** 待回复文本与发帖参考会发送给 DeepSeek，API 费用由使用者承担。仓库不包含运行中的密钥、私人运行记录或备份。

## 验证及限制

```bash
npm test
```

v3.0.15：**133 项自动测试通过**。包含调度、时间边界、回帖滚动 24 小时、多语言尾句、错误恢复和去重保护。

实号测试曾确认 3 条互动回复与点赞的 X 持久状态；多语言英文、日文、西班牙文生成测试通过，未公开发送这些语言测试文案。上述结果不等于 v3.0.15 所有模块已经完成长时间端到端验收。

X 页面、加载速度及网络可能影响执行；随机冷却不包含 AI 生成、查找目标、页面加载及发送确认耗时。仅本地保存的处理记录用于去重，不保证识别所有手动回复。使用时应遵守平台规则并审阅生成效果。
