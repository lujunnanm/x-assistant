# X 文案助手 v0.12.5

本地 Chromium 浏览器扩展，为 X 页面提供两个相互协调的循环模块：

- **互动模块**：按本地文案库执行回复、点赞与关注流程。
- **发帖模块**：在 600–900 秒窗口内随机选择触发时间，并从帖子文案库中轮换文案。

两个模块拥有独立倒计时。发帖执行前会暂停互动模块，发帖完成后恢复原互动状态。

## 安装

1. 打开 `chrome://extensions/`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录（包含 `manifest.json`）。
5. 打开或刷新 `https://x.com/`。

## 使用

- 点击对应模块的“开始”启动循环。
- 点击“结束”停止该模块后续动作。
- 文案库保存在扩展本地存储中，可通过控制面板更新和导入。
- 页面刷新或扩展重载后，正在运行的发帖循环会从原定触发时间恢复。
- 多个 X 标签页通过 Web Lock 协调，同一时间只有一个标签页执行发帖循环。

## 安全与状态边界

- 发送前会核对当前登录账号、唯一发帖入口、空白编辑器和唯一可用发送按钮。
- 已有弹窗、已有草稿、账号变化或定位不唯一时停止，不猜测点击。
- 只有检测到 X 的明确成功提示才记为发帖成功。
- “结束”不会撤回已经提交给 X 的请求。
- 浏览器休眠或 X 页面结构变化可能影响触发时间与控件定位。
