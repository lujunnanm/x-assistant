# 神圣计划 v8.0.12 · 高效工作链路

互动草稿恢复：真实草稿与打开的弹窗分开提示；隐藏的空弹窗节点不再阻塞恢复，隐藏但有内容的草稿、图片、投票和已选文件仍受保护。总开关及互动开启时，仅在未发送或发送已确认、任务已停稳且账号与原工作页一致的情况下，每 30 秒只读复查一次；阻塞消失后恢复原标签页，不清理草稿、不自动关闭弹窗、不另开窗口。未知结果、手动暂停、账号变化、平台限制和已关闭的工作页不自动放行。旧版持久阻塞须有同账号、同工作页的已停止运行证据才可恢复；没有证据仍需手动核对。旧运行的“任务已停止”显示为上轮记录，不再混入本次异常。

文案媒体入库：所有新文案默认启用；评论“+”携带所属原帖图片和动图，普通视频链接追加到文案末尾。保留已有手动停用状态，不因入库而开启总开关。

互动返回修复：浏览历史达到上限后，按稳定的条目 key、当前相邻关系和原来源 URL 核验返回，不再依赖会变化的旧索引。已确认回复正常返回；未发送且详情不匹配时，核实原搜索列表恢复后跳过该目标并继续，避免误进入永久阻塞。真正的来源变化、手动操作、草稿和未知发送仍保持保护；不清空记录或缩短冷却。

回关恢复：自动核对完成后，同一工作页根据该账号、该运行的已保存结果解除旧阻塞，再按原有授权和冷却启动。不自动放行仍待核对或手动停止的任务。回关模块已启用却未运行时，控制台显示「未运行」，不再误显示普通冷却。

回帖补查：X 折叠回复与评论未全部显示分开提示，不自动展开疑似垃圾回复，不把缺口记为完成。同一原帖的计数缺口重复且不变时，单帖补查间隔依次延长至 30、60、120 分钟；资料页回复计数变化时立即恢复核查。其他帖子、提及扫描、发送去重和模块故障恢复不受影响。

回关完整遍历：后台「回关设置」新增默认关闭的「完整遍历回关」。开启后，回关模块从认证关注者列表顶部持续扫到末尾；每次回关后的 55–70 秒冷却直接用于继续刷列表和预找下一位，到点再按最新页面状态执行。整轮到达末尾后自动关闭完整遍历和回关模块，不再从头重复。

回关结果自动核对：关注后仍以同账号、同数字 ID 的原生「正在关注」状态确认。短时未确认的记录由原回关工作页自行重新遍历核对；确认已关注则记成功，稳定确认仍未关注则记失败并恢复模块，不再显示人工「核对结果」按钮，也不会重复点击未核实目标。

回关限流修复：仅原生可见提示明确表示频率限制时，回关暂停 30 分钟后原页恢复。点击后遇到限流，先持久保存本次目标并跳过该目标，不重复关注；限流记录保存失败仍停止。关注人数上限、账号限制、普通无法关注与无回执不冒充速率限制。

自动恢复：四个模块的普通可恢复错误在 30 秒后由后台恢复，30 秒巡检节拍下通常在 1 分钟内执行；明确速率限制等待 30 分钟后恢复。沿用原标签页和窗口，不清空账本或业务冷却。已确认回复后的返回失败可恢复扫描但不重发。手动停止、账号/登录异常、未处理草稿、结果未知和工作页关闭不自动恢复。等待状态持久保存；浏览器退出、休眠或系统延迟期间不保证准点执行，恢复运行后核验再处理。

本版自动关注规则：互动回复确认后，只将作者写入独立持久化关注队列，立即继续下一轮互动。队列在同一浏览器窗口内复用一个不抢焦点的后台标签页，按原有关注间隔处理，按账号和作者去重，不占用互动时间线。找帖和生成回复不等待关注；实际发送与关注仍遵守共享动作间隔。

关闭自动关注、互动或总开关会暂停队列，重新开启后继续待处理项。已关注不重复点击，点击结果未知不自动重试。页面异常在原后台标签页处理，不反复新建；修复后关闭再开启自动关注可解除队列暂停，只有确认原标签页已关闭才重建。队列结果记入原帖处理记录和后台日志。

恢复规则：发帖、互动、回帖和回关出错后，点击恢复复用原工作标签页和原窗口；只有确认原页已关闭才新建。保留互动当前搜索词及业务冷却。原页有草稿或离开 X 时提示在原页处理，不通过另开页面绕过。总开关关闭时恢复不会启动任务。

本版按原有功能重构高频观察、状态同步与回帖遍历，不重写已稳定的发送事务。
界面、存储键、配置、文案库、AI 规则、动作间隔和功能开关兼容原版。

- 「+」：一次发现、批量查库；自身按钮更新不再触发重复查库。库发生变化才刷新已有按钮，同一时间只发一个状态查询。
- 工作页：心跳时间变化不再引起所有页面重新查询任务；启停、任务归属和真实故障变化仍立即响应。
- 控制台：只响应有关模块的存储键，不再因每条回复账本写入而重绘所有模块。
- 回帖：后台长等待降低唤醒频率；处理完当前屏新评论后继续下拉；保留待处理原帖优先补查。
- 保留必要边界：账号、目标、去重及未知发送；不减少业务间隔，不重置发布计时，不对平台失败盲目补发。
- 无新增运行依赖、权限或配置迁移；本地改动与浏览器重载分开执行。

保留石墨灰纹理、橙色按键与倒计时、图标、字体、圆角、右下角位置及原显示尺寸。一个总开关控制服务，四个独立执行器各在插件创建的工作页运行；普通浏览页只显示控制台，不抢页面、不执行任务。

## 使用

四个模块的倒计时均显示整秒，不显示小数；达到一分钟显示“分:秒”。此格式不更改实际动作间隔。

悬浮框的普通说明已精简；点击浏览器工具栏的神圣计划扩展图标可打开设置和日志。故障或结果未知时，仅相应模块的图标变红，不再显示整行错误小字。控制台级故障使用标题图标提示，恢复与核对按钮仍可用。

1. 刷新旧 X 页面，登录原账号。
2. 在设置页「发帖文案库」粘贴并保存自己的文案。旧混合文案库不会自动导入新库。
3. 在悬浮框按需点击小图标打开「发帖」「互动」「回帖」「回关」，再点击「开启神圣计划」。四个模块各有独立开关和工作页，默认发帖关闭；空文案库不能开启发帖。点击模块名称（不是小图标）可查看对应工作页。
4. **发帖、互动、回帖和回关均按各自开关全天 24 小时运行。** 发帖仍服从文案库、发布周期、共享动作间隔与发送前安全检查，不会因为改成全天运行而追赶补发。浏览器重启或扩展升级后总开关保持关闭，需手动开启。
5. 点击总开关关闭全部。设置页还保留“停止全部模块”应急操作。关闭不会撤回已经提交的请求。

**X 全页面一键改写入库**：主页任意时间线、搜索、个人资料、帖子详情和通知等页面都生效。长帖会先原地展开全文。普通帖子保留事实、核心立场与主要语言，但不沿用原文语气；必须改变开头、叙述顺序、句式和表达节奏。评论会读取已加载的所属帖子正文，把帖子和评论的补充、延伸、对比或冲突关系融合成同一个人的完整观点；成稿只允许一个叙述者、一个说话主体、一套语气和一条连贯逻辑链，不写成回复、转述、两方辩论或两段拼接稿。帖子和融合后的评论都按整稿用途选风格，判不准时沿用常规改写。成稿一句一行；常规稿不留空行，夸张反应和克制求证稿句间留一行。每个“+”显示前会批量核对文案库；只要该帖子或评论的改写稿仍在库中，所有页面中的同一来源都显示“✓”并禁用，后台也会再次按帖子 ID 或主来源链接拦截，不调用 DeepSeek，不重复入库。从文案库删除对应稿件后，可见按钮会恢复为“+”。如果当前列表没有加载评论所属帖子，按钮仍会显示，点击时会提示打开评论详情后重试，不会只拿评论冒充融合稿。该功能只追加文案，不开启发帖。图片和动图按原始字节保存为本地附件，支持 JPEG、PNG、WebP、GIF；X 原生动图使用其 MP4 原件，在文案库静音循环预览，不转成截图或正文链接。每个附件不超过 5 MB，原帖与评论去重后合计最多 4 个；超限、类型不符或任一附件无法读取时整条不入库。不取引用卡、头像或视频封面，不把媒体发给 DeepSeek。仅在点击“+”时访问 X 媒体 CDN；MP4 动图仅接受 video.twimg.com 的 tweet_video 路径。普通视频仍把绑定该帖的 X 视频页面链接（/video/N）追加到成稿末尾，不下载普通视频。原帖只有媒体而没有文字时，只改写评论文字，不编造媒体内容。有正文时改写和媒体须均成功才入库；纯图、纯动图或纯视频链接无需 API 密钥。发帖时按原媒体类型交给 X 原生上传入口，未就绪、数量不匹配或入口不支持时不提交。

**回关（默认关）**：打开总开关和「回关」后，插件在独立后台工作页检查当前账号的「认证关注者」列表。从列表顶部按显示顺序向下检查。遇到首个符合条件、明确显示「回关」的账号，就在原有间隔到点后核对并回关。确认成功一人后的 55–70 秒冷却用于继续向后刷列表和预找下一位，到点再按最新页面重新定位，避免空等。后台「完整遍历回关」开启时，整趟只从顶部扫到末尾一次，完成后自动关闭该开关和回关模块；关闭时保留原有持续检查及完整空扫后的前 6 屏规则。结果未确认时由原工作页自动核对同账号同 ID 的关注状态；已经关注、关注请求待处理、身份或归属不能确认的都不点。这个模块不需要 AI，也不依赖「互动」或「自动关注」开关。

在后台「互动设置」中开启搜索后，可以每行填写一个关键词或短语，最多 20 个，按顺序轮换。留空沿用默认 AI 搜索词。关键词用于取得 X 搜索结果，正文不必包含当前关键词。关闭搜索则直接从选定的 X 首页时间线选帖，不使用搜索词或 AI 主题筛选。首页和搜索共用曝光滑块：0–100,000，每档 100，调整完成自动保存并用于筛帖。只互动曝光量大于滑块值的帖子，等于门槛或不可读时跳过。5,000 仅为未配置时的默认值；改变门槛不会启动互动，也不会改变冷却。

**搜索时间线换词**：搜索开启且互动运行时，在工作页使用 X 原生搜索、切换热门／最新，或在「互动搜索词」中输入关键词后按回车或「应用」，都能沿用同一互动任务。新词只对该工作页有效，不覆盖后台轮换列表，也不修改曝光滑块或重置冷却。旧来源未提交的候选作废，新结果确认加载后再筛选；点击「恢复后台词」恢复后台关键词轮换。未确认的发送、草稿及离开支持的搜索列表仍受原有保护。

**首页时间线**：搜索关闭时，可在首页顶部任意标签（为你推荐、正在关注、AI 及其他自定义标签）开启互动，独立工作页会使用并记住所选标签。点击悬浮框「互动」可打开工作页，直接切换原生标签即可更换来源，不增加开关、不自动轮换标签。普通浏览页随意切换标签不会干扰正在运行的工作页。切换后须等待新列表真正加载；AI 生成和进入详情前核验来源，返回时也核对原标签。只有确认未发送的旧候选才会放弃重选；已确认或结果未知的回复不会补发。曝光门槛、无点赞、共享间隔和其他模块保持不变。

浏览器须保持运行且电脑唤醒；休眠、后台渲染、网络故障可能推迟动作，不会补发追赶。无有效文案、登录、互动／回帖所需 AI 配置或存在未知发送时，相应模块会等待或阻断，不会强行操作。

## 发帖文案库

设置页「发帖文案库」只保留“启用／停用”：可添加、编辑、启停、删除、批量粘贴及导入导出；批量模式可按行或用单独一行 `---` 分隔多行帖子。所有新入库的未发布文案默认启用，包括新建、粘贴、导入及「+」保存的文字、配图、动图和视频链接稿；手动停用的已有文案在编辑、刷新、升级后仍保持停用。明确标记为已发布或结果未知的旧稿仍停用，未经核对不自动重新启用。导入或升级时会从发布正文删除独立的“（AI概念配图）”说明行，以及与 `sourceUrls` 匹配或紧随该说明的独立来源链接；来源仍作为库内元数据保留，不会发布。发帖模块严格按文案库从上到下选择第一条启用文案，按清理后的正文填入 X 原创发帖框，不调用 AI 改写；平台回执确认发布成功后，在同一次后台存储提交中删除该文案并更新下一次发帖时间。失败或结果未知时不删除，未知稿经人工核对后自动停用，再继续下一条。库内没有启用文案时自动关闭发帖开关。目标账号、有效期、草稿、待发、一次性发布和文案级发布记录已移除；账号校验、发帖间隔、平台回执、运行时未知结果停机和发送前安全检查保持不变。

升级时旧混合文案库只备份一次到插件存储 `xAssistantLegacyCopyBackupV1`，随后清空 `app.rows`，不再自动恢复旧的 200 条文案；互动和回帖使用各自原有的回复流程，不读取新发帖库。已有未知发送结果须先核对。需要本地旧库副本时，请在升级前从旧版导出。

## 删帖管理

进入扩展设置左侧的「删帖管理」，扫描本人资料页。它不会开启发帖、互动或回帖。候选区区分明确交友邀请、精准交友标签和需要人工判断的帖文；可以逐条取消。只有确认过的固定清单才允许删除，且会在实际点击前重新比对账号、原帖 ID 和全文。回帖、转帖、引用和无法核实的内容不自动删除。结果未知立即停止，不补删。X 能加载的资料页不等于完整账户历史。删除线上帖子不会删除本地文案库。

## 本版后台修复

- 回帖列表中的评论若带 X 原生“显示更多”，进入同一评论详情后允许正文从已核对的预览前缀展开为全文；没有截断标记、前缀变化或帖子身份不一致时仍拒绝发送。

- 已编辑帖详情中的编辑时间链接仅用于核对当前帖子身份，不作为导航或发送按钮。工作页确实已不存在时清理失效的运行标记，未确认的外部操作仍需人工核对。

- 回帖从评论本身的唯一时间链接读取身份；引用卡片的时间和正文不能代替原评论。匹配不到目标或回复框时仍不发送。

- 互动搜索卡有“显示更多”时，先用该帖原生按钮原地展开，展开失败不生成、不发送。列表全文和详情全文仍需一致；不会把预览前缀当作目标凭据。
- 回帖返回资料页时核对原创帖身份，不再依赖旧卡片像素位置。评论未完全加载保留待查，回复未知不补发；回帖不再执行点赞或补点。
- 悬浮框区分当前卡住、结果未知、待查提示和上轮记录。完整原因、时间及目标仍可在提示详情或日志查看；卡住和未知结果保持警示。

- 发帖直接使用后台 X 首页的原创发帖框。账号、编辑框、发送按钮和上传控件必须在同一可验证上下文；有已有草稿、已有附件或目标变更就不发送。
- 搜索结果和详情不一致时绝不回复。只有确认尚未编辑或发送、无人操作，且已回到同一条搜索记录，才跳过这一帖；无法验证时保留现场，图标提示异常，原因可在日志查看。
- 扩展升级后撤销旧工作页的任务权限、保留旧页和业务记录。总开关保持关闭；下次手动开启后使用新工作页。旧页面若提示扩展已更新，请先保存自己的草稿，再刷新该页。
- 回帖正常运行时逐屏检查本人原创帖，详情返回后核对可见卡片位置；回不到原处则保留未访问项，继续检查提及。发帖文案库删除和清空使用页内确认，默认取消。

- 工作页保持在后台。互动与回帖从准确的时间链接进入目标详情，核验原帖和唯一行内回复框后再输入，不依赖 X 弹窗获得前台焦点。
- 个人主页按真实链接重定位；本人原帖详情读评论时可短时唤醒 X 已请求的渲染回调，不修改可见性、不激活工作页。加载不全留在队列，不把“没显示”当成“已处理”。
- 悬浮框显示当前状态；异常不展开成长文字，原因与目标可在日志核对。重载后后台 12 秒未响应时提示重载/刷新；未知提交不得补发。

## 固定节奏

- 发帖、互动回复、回帖共用 **至少 23 秒** 的发送间隔；关注同时服从这一动作间隔。
- 连续两次认证回关等待 **随机 55–70 秒**；只要前后任一次是互动模块的普通关注，仍需间隔 **至少 120 秒**。后台挂起或没有合格候选时可能更久，不补做错过的操作。
- 互动与回帖均不申请点赞许可，也不会因为旧点赞记录跳过待回复评论。目标核验、回执、网页或浏览器休眠可使实际动作更晚。
- 间隔从实际点击后的后台确认时间计算，持久化保存；刷新、停止、重启不清除。未收到确认的动作许可按最晚可能点击时间保守计时。
- 原发帖 20–30 分钟等业务冷却继续有效；设置为更短的值也不能突破固定下限。

## 模块与保护

- 发帖：独立首页工作页，使用可编辑原文库、发帖周期与回执核验；本版不从旧混合库读取文案或配图。
- 互动：独立工作页，按搜索开关使用话题搜索或首页时间线，按时间线来源、曝光量和去重规则选帖，保留自动关注选项；对帖子只回复、不点赞。后台拒绝互动模块的点赞许可。
- 回帖：独立个人主页工作页，沿用本人原创帖评论扫描、逐条回复和提及补扫；不点赞。
- 回关：本人认证关注者名单专页；每轮只处理一个可以确认身份、且明确显示「回关」的账号。
- 每个模块独立控制器、循环、运行记录与错误；一个故障不主动停止其他模块。只共用账号配置、回复去重及固定动作节奏。
- 页面、账号、编辑器或目标变化，阻断受影响模块。关闭或挪用工作页后，不无限重开页面；控制台显示原因和“恢复”。
- 明确未提交的临时网络错误有限退避；未知发送保留证据，不重发。点击前最后一刻再次校验时间、账号、页面、目标和许可。
- 停止或权限撤销后，已点击的发送可最多读取 15 秒回执，不把已成功发送误记为失败，也不继续发新内容；跨午夜不再暂停发帖。

## 实现接口与依赖

无 npm 运行依赖。需支持 Manifest V3 和 Web Locks 的 Chromium 浏览器、X 登录、有效 DeepSeek 配置。

| 文件 | 职责 |
| --- | --- |
| `console.js` / `view.js` / `overlay.css` | 统一控制台及原视觉 |
| `managed-service.mjs` / `service-policy.js` | 总开关、托管页、北京时间窗口和有限重试 |
| `followback.js` | 认证关注者名单核对、逐一回关和回执确认 |
| `workspace.js` / `workspace-policy.js` | 工作页授权、导航、取消与独立故障处理 |
| `posting.js` / `overlay.js` / `notifications-driver.js` | 发帖、互动、回帖执行器 |
| `action-gate.mjs` / `action-client.js` | 共享动作间隔、认证回关与普通关注的独立冷却 |
| `background.js` / `state.mjs` / `posting-copy.mjs` / `runtime-client.js` | 持久化、发帖原文库、标签／文档／runId 所有权及原子回复占位 |
| `reply-engine.js` / `posting-receipt.js` | 发送事务和回执证据 |

动作接口为 `XAssistantActions.click({module,runId,account,kind,signal,beforeClick,validate,click})`；仅托管页有效，`validate` 和 `click` 必须同步。`beforeClick` 仅在获得许可后执行，取消等待不会留下虚假的已提交记录。业务扫描不申请动作许可。

旧 `scheduler.js`、`scheduler-core.js`、`coordination.js` 不在 manifest 加载列表，不参与运行，仅保留历史回归参照。

## 运行中管理文案

发帖运行时可编辑、停用、启用、删除单条文案，也可在库尾新增。开始填入到回执确认期间只锁定当前稿件；其他稿件可照常修改。打开编辑器前核对文案库版本，发现变化时重选，不发送旧稿，也不重置已有倒计时。清空或批量改序仍需先暂停发帖；发送结果未知仍需先核对。

## 互动来源和筛选

搜索默认轮换 30 组 AI 搜索词，也支持自定义。插件直接使用 X 返回的搜索结果，不额外检查正文是否包含关键词。首页使用选定的时间线，不限定主题。曝光量从帖子原生统计读取，缺失或不高于滑块值均跳过。纯图或纯视频帖可用本地文案库问候，不编造媒体细节；AI 回复过长也回退到文案库。

关注关系不影响帖子能否入选；同一作者的不同帖子可分别互动。仅在确认对方没关注你时添加回关尾句，和自动关注开关无关。若你尚未关注对方，自动关注开启时，在回复确认后加入独立关注队列；关注间隔等待仅发生在队列，不阻塞互动循环，不受对方是否关注你影响。关系不明不推断。关注冷却、同一帖子去重、身份校验及未知发送保护保持不变。不修改其他三个模块、发帖文案库或用户开关。新版本需安全暂停并重载才会在运行页生效，重载后总开关保持关闭。
