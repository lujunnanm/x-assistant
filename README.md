# 神圣计划 v7.3.2 · 托管工作页

保留石墨灰纹理、橙色按键与倒计时、图标、字体、圆角、右下角位置及原显示尺寸。一个总开关控制服务，四个独立执行器各在插件创建的工作页运行；普通浏览页只显示控制台，不抢页面、不执行任务。

## 使用

四个模块的倒计时均显示整秒，不显示小数；达到一分钟显示“分:秒”。此格式不更改实际动作间隔。

悬浮框的普通说明已精简；点击浏览器工具栏的神圣计划扩展图标可打开设置和日志。故障或结果未知时，仅相应模块的图标变红，不再显示整行错误小字。控制台级故障使用标题图标提示，恢复与核对按钮仍可用。

1. 刷新旧 X 页面，登录原账号。
2. 在设置页「发帖文案库」粘贴并保存自己的文案。旧混合文案库不会自动导入新库。
3. 在悬浮框按需分别打开「发帖」「互动」「回帖」「回关」，再点击「开启神圣计划」。四个模块各有独立开关和工作页，默认发帖关闭；空文案库不能开启发帖。点击模块名称可查看对应工作页。
4. **仅发帖**按北京时间 **06:00–24:00** 工作，**00:00–06:00** 休息；总开关与发帖开关同时开启时，06:00 自动恢复发帖。**互动、回帖、回关按各自开关全天运行，不受发帖时段影响。** 浏览器重启或扩展升级后总开关保持关闭，需手动开启。
5. 点击总开关关闭全部。设置页还保留“停止全部模块”应急操作。关闭不会撤回已经提交的请求。

**回关（默认关）**：打开总开关和「回关」后，插件在独立后台工作页检查当前账号的「认证关注者」列表。每轮最多回关一人；已经关注、关注请求待处理、身份或归属不能确认的都不点。结果未确认时保留记录，不自动补点。这个模块不需要 AI，也不依赖「互动」或「自动关注」开关。

总开关和「互动」开启时，左侧图标只选来源：橙色（搜索开）从交友话题搜索结果找帖，灰色（搜索关）从 X 首页时间线找帖。两种来源沿用相同的筛选和冷却。要停止互动，请关闭「互动」或总开关；红色图标仍表示异常。

浏览器须保持运行且电脑唤醒；休眠、后台渲染、网络故障可能推迟动作，不会补发追赶。无有效文案、登录、互动／回帖所需 AI 配置或存在未知发送时，相应模块会等待或阻断，不会强行操作。

## 发帖文案库

设置页「发帖文案库」可添加、编辑、停用、删除及批量粘贴文案；批量模式可按行或用单独一行 `---` 分隔多行帖子。发帖模块随机轮选启用的条目，按库内原文填入 X 原创发帖框，不调用 AI 改写。发帖间隔、回执核验、未知结果不补发和发送前安全检查保持不变。

升级时旧混合文案库只备份一次到插件存储 `xAssistantLegacyCopyBackupV1`，随后清空 `app.rows`，不再自动恢复旧的 200 条文案；互动和回帖使用各自原有的回复流程，不读取新发帖库。编辑文案请先暂停发帖，已有未知发送结果须先核对。需要本地旧库副本时，请在升级前从旧版导出。

## 删帖管理

进入扩展设置左侧的「删帖管理」，扫描本人资料页。它不会开启发帖、互动或回帖。候选区区分明确交友邀请、精准交友标签和需要人工判断的帖文；可以逐条取消。只有确认过的固定清单才允许删除，且会在实际点击前重新比对账号、原帖 ID 和全文。回帖、转帖、引用和无法核实的内容不自动删除。结果未知立即停止，不补删。X 能加载的资料页不等于完整账户历史。删除线上帖子不会删除本地文案库。

## 本版后台修复

- 已编辑帖详情中的编辑时间链接仅用于核对当前帖子身份，不作为导航或发送按钮。工作页确实已不存在时清理失效的运行标记，未确认的外部操作仍需人工核对。

- 回帖从评论本身的唯一时间链接读取身份；引用卡片的时间和正文不能代替原评论。匹配不到目标或回复框时仍不发送。

- 互动搜索卡有“显示更多”时，先用该帖原生按钮原地展开，展开失败不生成、不发送。列表全文和详情全文仍需一致；不会把预览前缀当作目标凭据。
- 回帖返回资料页时核对原创帖身份，不再依赖旧卡片像素位置。评论未完全加载保留待查，回复未知不补发；回帖不再执行点赞或补点。
- 悬浮框区分当前卡住、结果未知、待查提示和上轮记录。完整原因、时间及目标仍可在提示详情或日志查看；卡住和未知结果保持警示。

- 发帖直接使用后台 X 首页的原创发帖框。账号、编辑框、发送按钮和上传控件必须在同一可验证上下文；有已有草稿、已有附件或目标变更就不发送。
- 搜索结果和详情不一致时绝不回复。只有确认尚未编辑或发送、无人操作，且已回到同一条搜索记录，才跳过这一帖；无法验证时保留现场，图标提示异常，原因可在日志查看。
- 扩展升级后撤销旧工作页的任务权限、保留旧页和业务记录。总开关保持关闭；下次手动开启后使用新工作页。旧页面若提示扩展已更新，请先保存自己的草稿，再刷新该页。
- 回帖正常运行时逐屏检查本人原创帖，详情返回后核对可见卡片位置；回不到原处则保留未访问项，继续检查提及。发帖文案库删除和清空使用页内确认，默认取消。

- 工作页保持在后台。互动与回帖从准确的时间链接进入目标详情，核验原帖和唯一行内回复框后再输入，不依赖 X 弹窗获得前台焦点。
- 个人主页按真实链接重定位；本人原帖详情读评论时可短时唤醒 X 已请求的渲染回调，不修改可见性、不激活工作页。加载不全留在队列，不把“没显示”当成“已处理”。
- 悬浮框显示当前状态；异常不展开成长文字，原因与目标可在日志核对。重载后后台 12 秒未响应时提示重载/刷新；未知提交不得补发。

## 固定节奏

- 发帖、互动回复、回帖共用 **至少 23 秒** 的发送间隔；关注同时服从这一动作间隔。
- 连续两次认证回关等待 **随机 55–70 秒**；只要前后任一次是互动模块的普通关注，仍需间隔 **至少 120 秒**。后台挂起或没有合格候选时可能更久，不补做错过的操作。
- 互动与回帖均不申请点赞许可，也不会因为旧点赞记录跳过待回复评论。目标核验、回执、网页或浏览器休眠可使实际动作更晚。
- 间隔从实际点击后的后台确认时间计算，持久化保存；刷新、停止、重启不清除。未收到确认的动作许可按最晚可能点击时间保守计时。
- 原发帖 20–30 分钟等业务冷却继续有效；设置为更短的值也不能突破固定下限。

## 模块与保护

- 发帖：独立首页工作页，使用可编辑原文库、发帖周期与回执核验；本版不从旧混合库读取文案或配图。
- 互动：独立工作页，按搜索开关使用话题搜索或首页时间线，沿用交友话题、筛选和自动关注选项；对帖子只回复、不点赞。后台拒绝互动模块的点赞许可。
- 回帖：独立个人主页工作页，沿用本人原创帖评论扫描、逐条回复和提及补扫；不点赞。
- 回关：本人认证关注者名单专页；每轮只处理一个可以确认身份、且明确显示「回关」的账号。
- 每个模块独立控制器、循环、运行记录与错误；一个故障不主动停止其他模块。只共用账号配置、回复去重及固定动作节奏。
- 页面、账号、编辑器或目标变化，阻断受影响模块。关闭或挪用工作页后，不无限重开页面；控制台显示原因和“恢复”。
- 明确未提交的临时网络错误有限退避；未知发送保留证据，不重发。点击前最后一刻再次校验时间、账号、页面、目标和许可。
- 停止或发帖跨午夜暂停后，已点击的发送可最多读取 15 秒回执，不把已成功发送误记为失败，也不继续发新内容。

## 实现接口与依赖

无 npm 运行依赖。需支持 Manifest V3 和 Web Locks 的 Chromium 浏览器、X 登录、有效 DeepSeek 配置。

| 文件 | 职责 |
| --- | --- |
| `console.js` / `view.js` / `overlay.css` | 统一控制台及原视觉 |
| `managed-service.mjs` / `service-policy.js` | 总开关、托管页、北京时间窗口和有限重试 |
| `followback.js` | 认证关注者名单核对、逐一回关和回执确认 |
| `workspace.js` / `workspace-policy.js` | 工作页授权、导航、取消与独立故障处理 |
| `posting.js` / `overlay.js` / `notifications-driver.js` | 发帖、互动、回帖执行器 |
| `action-gate.mjs` / `action-client.js` | 共享动作间隔、认证回关与普通关注的独立冷却 |
| `background.js` / `state.mjs` / `posting-copy.mjs` / `runtime-client.js` | 持久化、发帖原文库、标签／文档／runId 所有权及原子回复占位 |
| `reply-engine.js` / `posting-receipt.js` | 发送事务和回执证据 |

动作接口为 `XAssistantActions.click({module,runId,account,kind,signal,beforeClick,validate,click})`；仅托管页有效，`validate` 和 `click` 必须同步。`beforeClick` 仅在获得许可后执行，取消等待不会留下虚假的已提交记录。业务扫描不申请动作许可。

旧 `scheduler.js`、`scheduler-core.js`、`coordination.js` 不在 manifest 加载列表，不参与运行，仅保留历史回归参照。
