# 神圣计划 v3.0.6

本地 Chromium 扩展。沿用原悬浮窗风格，由一个总开关调度发帖、互动和回帖，三个模块显示状态灯。低曝光清理保留独立开关，与协同工作互斥。

## 协同规则

- 发帖优先：首轮保留原来的约 30 秒启动缓冲；后续随机间隔 30–50 分钟。交接时等待正在执行的互动安全结束，不并发发送。
- 互动在发帖冷却期工作，累计实际运行 60 分钟后休息 30 分钟。发帖暂停、页面睡眠不计入互动工时。
- 回帖仅在互动休息窗口内工作，每条间隔 10–30 秒，不再每 5 分钟检查。处理完本轮评论后等待下一窗口。
- 回帖在下一次发帖或互动开始前 30 秒停止接收新任务。发帖完成后，若休息窗口仍有时间，继续未完成批次。
- 临近截止的 AI 请求可被放弃；迟到的生成结果不会触发发送。已经提交的发送等待回执，不硬切后自动重试。
- 普通可取消弹窗、未发送回复残留：取消并跳过当前条目。无法安全关闭的验证弹窗、未知发送结果停止协同，等待人工处理。
- 总开关可从 X 各页面启动并通过导航进入主页。保护非弹窗中的内联草稿，不强制覆盖。

## 保留的重要功能

DeepSeek 发帖和回复、文案库管理、自动关注选择、不关注时高于 5000 曝光筛选、六次滚屏无目标刷新、跨标签页锁、账号校验、平台发送回执、永久去重和未知发送保护。

通知首次建立最近 24 小时边界，按账号及评论 ID 保存记录；已确认、跳过和 Grok 评论不重复处理。回帖不附加“交个朋友／请回关我”尾句。AI 可以跳过不适合回复的内容。

清理仍为每隔 10–30 秒检查一条发布超过 24 小时、曝光低于 50 的本人原创帖子，排除回复、转帖、文章、置顶和推广。

## 安装与桥接

在浏览器扩展页加载本目录，刷新 X。不要同时启用旧版与新版。安装、更新或浏览器重启后默认停止；仅已启动的协同在同标签页正常刷新时恢复安全等待状态。

```bash
python3 bridge/deepseek_bridge.py
```

在 `http://127.0.0.1:18765/` 保存 API Key。Key 由本地服务进程持有，不写入扩展源码。服务重启后需重新配置。桥接的 `EXT` 应与实际扩展 ID 一致。

## 逾期重启

保存的下次发帖时间已到或已过：启动后立即进入生成与发帖流程，先等待正在进行的页面操作安全交接，不再额外等待 30 秒。仅执行一轮，成功后按本次成功时间重新安排 30–50 分钟冷却，不追补错过的多轮。尚未到期则继续等待原时间；首次无计划仍保留 30 秒启动缓冲。未知发送结果仍须核对，不自动重发。
